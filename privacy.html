3. Цели обработки

Ваши данные обрабатываются исключительно для следующих целей:

  • Оформление, сборка и доставка вашего заказа;
  • Связь с вами для уточнения деталей заказа (включая уточнение фактического веса товаров);
  • Уведомление о статусе заказа (через Telegram-бота);
  • Направление информационных сообщений о скидках и акциях (рассылки).

4. Действия с персональными данными

Оператор осуществляет сбор, запись, систематизацию, накопление, хранение, уточнение (обновление, изменение), извлечение, использование, обезличивание, блокирование и удаление ваших персональных данных. Обработка осуществляется с использованием средств автоматизации (через Google Таблицы и Telegram API) и без их использования.

Ваши данные не продаются и не передаются посторонним лицам. Однако, для обеспечения работы системы, данные могут обрабатываться следующими сервисами:

  • Telegram (как платформа для мессенджера и Mini App);
  • Google (сервис Google Apps Script и Google Таблицы, используемые для хранения и обработки базы заказов);
  • Служба доставки (РУП «Белпочта» / «Европочта») — только для передачи адреса и ФИО получателя.
